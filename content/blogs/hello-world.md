## 关于「全能」

我想成为全能的人，不是因为贪心，而是因为**不想再被生活挑拣**。
能自己修好一台电脑，也能把一段文字写得干净；能扛住低谷，也能在晴天里笑出来。

行内代码长这样：`pnpm dev`，它用了破晓金做底。

```ts
// 代码块是安静的浅色底
export function tomorrow() {
  return '会更好'
}
```

> 经历曲折不是失败，
> 是让你身上的颜色更清楚。
